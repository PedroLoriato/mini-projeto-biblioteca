## Sistema de Empréstimos da Biblioteca do Campus

> Mini projeto desenvolvido para a disciplina de **Tópicos Especiais II**, consistindo em uma **API REST** para o gerenciamento de empréstimos da biblioteca do campus.

---

### Tecnologias Utilizadas

* **Linguagem:** Java 21
* **Framework:** Spring Framework 4.1.2
* **Arquitetura:** API REST
